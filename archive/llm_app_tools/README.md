# Архив одноразовых проверок llm_app

Здесь сохранены `ask5`, `test_php`, `run_audit_windows`, `run_wide_windows` и `report_wide_current`. Они относятся к прежним опытам, фиксированным моделям, настройкам и расположению результатов. Это исторические материалы, не инструменты RAMVI и не поддерживаемые команды запуска. Не использовать их для нового экзамена без отдельной проверки параметров и путей.

Для нового запуска используются параметризованные инструменты в [ramvi/engine/tools](../../ramvi/engine/tools/) и [описание переноса](../../ramvi/docs/architecture/TOOLS_MIGRATION.md). Данные, модели и результаты не перенесены в git.
