# Как устроен мозг (для проверки: что общее, а что сделано руками)

Состояние на 2026-11-10. Описан **основной мозг** — тот, что прошёл ступени
по порядку: сложение → вычитание → умножение → деление → чтение → правило
мягкости → цифры → знак «−» → память. Каждая ступень училась поверх
предыдущей, прежнее повторялось вперемешку. Ступень «логика» на основном мозге
пока не получилась (см. конец).

Отметки:
- 🟢 **общее** — правило работы нейронов и связей, ни про какую задачу не знает;
- 🟡 **врождённое устройство** — сделано руками, общее по форме, но придумано под класс задач;
- 🔴 **ручная проводка / настройка под ступень** — сделано руками под конкретную задачу.

## 1. Ядро: нейроны и связи 🟢

| что | как работает |
|---|---|
| Нейрон | копит заряд, при пороге срабатывает, заряд стекает, после срабатывания короткий отдых |
| Связь | передаёт сигнал с задержкой; сила меняется от того, кто раньше сработал (раньше — крепнет, позже — слабеет) |
| Миелин | задержка связи подстраивается под то, когда срабатывает получатель |
| Торможение | тормозящие связи гасят заряд; часть из них учится («мешал» — слабеет, «правильно не дал» — крепнет) |
| Награда | связи, участвовавшие в действии, крепнут от награды и слабеют от наказания |
| Закрепление | окрепшая связь становится устойчивой; ослабленная до минимума запоминается как «так нельзя» (отрицательная память); трижды неверное закреплённое освобождается для переучивания (сомнение) |
| Запас входов | общая сила входов нейрона ограничена — рост одного входа отнимает у других |
| Минимум путей к действиям | путь к действию не слабеет ниже минимума (чтобы всегда можно было переучиться) |
| Подстройка нейронов | часто работающий нейрон поднимает себе порог, редкий опускает |
| Контексты | нейрон-контекст, пока недавно горел, включает у всех связей свою добавку к силе (одни и те же пути — по-разному при разных знаках) |
| Ожидание награды | связи учатся на разницу «получил минус ожидал» (подключается не везде) |

## 2. Механизмы роста и поиска 🟢 (с оговорками)

| что | как работает | оговорка |
|---|---|---|
| Рост связей | если Y раз за разом срабатывает через N шагов после X, растёт связь X→Y | 🟢 |
| Нейроны-сочетания | если X и Y часто горят вместе, растёт нейрон «X+Y», загорается только от обоих | 🟢; **окно совпадения** (вместе = в пределах 3 шагов) включено только для памяти 🔴 |
| «Бывает вместе» | связи между тем, что видно, и тем, что слышно, по доле совместных появлений | 🟢 |
| Выбор победителя | в группе (звуки) звучит самый поддержанный; **вспоминать только по надёжной связи** (не меньше 3/4 силы) | 🟢 |
| Любопытство | шум у действий; растёт после неудач | 🟢 |
| Скука | молчание подряд толкает действия | 🟢 |
| «Проиграл — смени» | наказанное действие ненадолго подавляется; **по ситуации** — в той же ситуации подавляется дольше | 🟢 / по ситуации — таблица 🟡 |
| Поиск только по вопросу | шум и скука — только после сигнала-вопроса | 🟡 (кто вопрос — задано руками) |
| Найм детекторов | новое сочетание сработавших нейронов зрения получает свой нейрон-детектор | 🟡 — это **таблица** «событие → нейрон» в коде |
| Залипание | нейрон, сработавший от сильного входа извне своей области, горит сам, пока его не затормозят | 🟢 (какие нейроны умеют залипать — задано руками 🔴) |

## 3. Врождённые устройства 🟡 (здесь основная «мануальщина»)

| устройство | что делает | под какую задачу появилось |
|---|---|---|
| **Накопитель** | держит целое число; вход прибавляет выученное число порций, «ещё» отнимает одну; на вопрос говорит «ещё есть»/«лишнее» | счёт (сложение) |
| — регистр в накопителе | второе число: карточка кладёт, гость прибавляет содержимое | умножение |
| — «увиденные» входы | детекторы картинок прибавляют выученное число (цифра 3 = 3 порции) | цифры |
| — роли символов | цифра после нейрона роли работает как «столько-то раз событие» (после «−» — как конфеты); какая роль — учится | знак «−» |
| **Защёлка вопроса** | помнит, какой вопрос задан в этот день, и зажигает его нейрон на «отвечай» | вычитание (два вопроса) |
| **Заготовки** (14 штук) | счётчики «по одной» / «по регистру»; сеть выбирает, какой верить; после 10 удач подряд правило закрепляет выбор | деление |
| Утро | накопитель, защёлка и заготовки **обнуляются кодом мира** каждый день | счёт (единственное место, где мир обнуляет мозг) |

## 4. Ручная проводка и настройки по ступеням 🔴

| ступень | что задано руками |
|---|---|
| сложение | входы мира (карточка, конфета, дверь, гость, вопрос); действия «ещё»/«готово»; связи «всё ко всем»; у входов и действий нет подстройки порога; пути к действиям меняются только по награде |
| вычитание | датчики к действиям — слабые неизменные; обучаемое торможение только у сочетаний; место под рост 12 нейронов; сочетания только из входов |
| умножение | регистр в накопителе |
| деление | 14 заготовок; правило «10 удач подряд — закрепить» |
| чтение | 16 нейронов зрения, 8 звуков, 12 мест под детекторы; «бывает вместе» буквы↔звуки с окном 72 шага; звуки — группа соревнования |
| правило мягкости | признак мягкости — отдельный звук; рост к звукам только от детекторов букв; задержки не тают от простоя |
| цифры | 12 мест под детекторы; все детекторы — «увиденные» входы накопителя; старые веса накопителя учатся в 100 раз медленнее |
| знак «−» | нейроны ролей по одному на событие мира; разбор «какая роль дала бы верное число» после праздника; наказание за молчание (только мешавшим тормозам); сомнение не чаще раза за день |
| память | буфер из 3 залипающих нейронов **на каждый детектор и каждый звук**; восприятие **тормозит буферы своего чувства** (проводка задана руками); вопросы «что видел?/что слышал?» и действия ДА/НЕТ; у памяти нет прямых связей к ответам; вопрос→ответ слабая неизменная; окно совпадения 3 шага только для памяти; поиск только после вопросов; избегание по ситуации (вопрос + память); отрицательная память без замедления (для всего мозга с этой ступени) |

## 5. Что мозг выучил сам (не задано)

- сколько порций прибавляет каждое событие (гость +1, конфета −1, карточка → в регистр);
- когда говорить «ещё», когда «готово» (нейроны-сочетания вопроса и знака накопителя);
- какой заготовке верить при делении;
- какая буква — какой звук; что после «e» буква мягкая;
- что значит каждая цифра (сколько прибавляет);
- что «−» значит «конфеты уходят» (связь знака с ролью);
- в памяти — какой вопрос к какому буферу относится и что отвечать.
