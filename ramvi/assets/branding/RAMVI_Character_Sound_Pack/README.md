# RAMVI Character Sound Pack 1.0

Оригинальные синтезированные звуковые эффекты для персонажа RAMVI.

## Состав

- `emotions/` — звуки эмоций (радость, удивление, недовольство, злость, грусть, задумчивость, сонливость и др.)
- `ui/` — кнопки, окна, подтверждение, ошибки, уведомления и задания
- `character/` — электронные реплики, реакции, смешки, сонное бормотание
- `motion/` — моргание, появление, исчезновение, движения, кивок, idle
- `manifest.json` — машинный каталог файлов с длительностями и тегами
- `catalog.csv` — каталог для быстрой навигации

## Технические характеристики

Все WAV: PCM 16-bit, 48 kHz, mono, нормализованы до пика не выше ~ -2.4 dBFS. Речь не синтезируется: `talk_*` — условное электронное бормотание без слов; `chuckle_*` — мультяшные электронные смешки.

## Использование в RAMVI

Разрешайте наложение коротких звуков, но ограничивайте частоту `hover`, `blink` и `idle_chime`. Громкость интерфейсных сигналов желательно регулировать независимо от TTS. `talk_*` можно использовать как временную заглушку до подключения настоящего голоса и lip-sync.

Пример привязки событий:

```json
{
  "emotion.happy": ["emotions/happy_01.wav", "emotions/happy_02.wav"],
  "emotion.surprised": ["emotions/surprised_01.wav", "emotions/surprised_02.wav"],
  "character.blink": ["motion/blink_01.wav", "motion/blink_02.wav"],
  "character.idle": ["motion/idle_chime.wav"],
  "ui.confirm": ["ui/confirm_01.wav", "ui/confirm_02.wav"],
  "ui.error": ["ui/error_01.wav", "ui/error_02.wav"]
}
```
