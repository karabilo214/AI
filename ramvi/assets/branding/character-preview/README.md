# RAMVI Character Lab

Локальный стенд для подготовки 9.11. Откройте [index.html](index.html) обычным
браузером. Сервер, установка пакетов JavaScript, модель и интернет не нужны.
Исходные папки `RAMVI_Character_Pack` и `RAMVI_Character_Sound_Pack` должны
оставаться рядом со стендом, в `assets/branding/`.

## Что можно проверить

- Пять анимаций: покой и разговор повторяются, моргание/кивок/«нет» выполняются
  однократно с возвратом. Пауза, выбор кадра. Кивок и «нет» всегда 2×, остальные движения 1×.
- 13 готовых выражений, независимые слои глаз и рта, пять вариантов поворота.
- Idle построен из неподвижного выражения и лёгкого покачивания, без встроенного моргания.
  Отдельное автоморгание с паузами 3–6 секунд выключено по умолчанию. На повёрнутом лице
  моргание отключено, чтобы фронтальные слои не накладывались на другой ракурс.
- Тёмный/светлый/шахматный фон, размер персонажа, прозрачность краёв.
- 62 разрешённых звука по категориям, громкость, прослушивание и остановка.
  Электронные talk-реплики, shake_head и beep_no исключены: разговор и «нет» озвучиваются TTS.
  По умолчанию жесты беззвучны. Явное включение звуков добавляет короткие
  реакции к ручным жестам; автоматическое моргание остаётся беззвучным.
- Новый звук заменяет предыдущий; смена движения и скрытие вкладки останавливают
  звук. Скрытая вкладка не продолжает цикл отрисовки.

## Как устроено

Пакеты не изменены. `catalog.js` — проверенный снимок их манифестов для открытия
через `file://` без fetch/локального HTTP-сервера. `preview.js` содержит только
проигрыватель и UI; `preview.css` — собственные стили, без общей темы приложения.
Стенд ничего не сохраняет, не использует микрофон и не делает внешних запросов.

Кадры жестов исходного пакета используются напрямую для нейтрального лица.
Исходные кадры idle с морганием не используются.
Для остальных выражений моргание и разговор собираются из слоёв; кивок,
покачивание и idle используют простые перемещения изображения. Это
предварительная проверка сочетаний, а не новые нарисованные анимации.
Повороты из исходного пакета — деформация картинки, а не настоящие профили.
Для разговора и «нет» принят TTS; синхронизация с речью ещё не реализована.

## После изменения пакетов

Из корня репозитория (Python с Pillow):

```sh
.venv/bin/python ramvi/assets/branding/character-preview/build.py
node ramvi/assets/branding/character-preview/check.mjs
```

Сборщик проверяет существование и границы путей, размер 768×768/RGBA,
списки кадров, уникальность звуков и WAV PCM16 mono 48 kHz/длительности.
Текущий результат: 84 используемых PNG, 5 анимаций, 13 выражений, 69 звуков.
`preview_montage.wav` не входит в каталог отдельных реакций.

Проверка логики в Node прошла: загрузка без автозвука, возврат жестов,
цикл разговора/пауза/перемотка, сохранение мимики при моргании, слои лица,
замена и отмена звука/громкость, остановка скрытой вкладки и автоморгание.
Это проверки с подменёнными DOM/audio/canvas; визуальная плавность и качество
звуков требуют просмотра в браузере. При подготовке стенда подключение
управления браузером было недоступно, поэтому эта проверка ещё не пройдена.

Пакет ресурсов и проигрыватель уже перенесены в модуль Character
(`character/ramvi_character`, раздел «Персонаж» приложения).
Полный пункт 9.11 остаётся открытым: предстоят оценка материала владельцем,
устойчивый контракт пакета и подключение выбранного renderer в RAMVI.
