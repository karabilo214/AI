# Логотип RAMVI

`ramvi-logo-v1.png` — основной горизонтальный логотип приложения, PNG с прозрачным фоном. Исходный референс: `../../docs/spec/Character-Module/Ramvi-logo.png`; исходник сохранён без изменений.

Создан встроенным инструментом image_gen. Это растровый вариант; векторный мастер и отдельные системные иконки пока не подготовлены. Тёмная надпись рассчитана на светлую подложку.

## Промпт

Use case: logo-brand. Create a polished primary logo for the entire RAMVI AI application based on the supplied reference image. Reference role: existing mascot and brand palette. Preserve its recognizable rounded robot face, expressive friendly confident eyes, headphones, distinctive swept crest and purple/violet with warm coral accents. Simplify heavily into a clean professional compact emblem with clear silhouette, restrained gradients, crisp vector-like edges and enough detail to read at application-icon sizes. Remove all floating speech bubbles, checklists, lightbulb, particles, orbit rings and floor shadow. Do not make an illustration scene. Create one horizontal brand lockup: compact robot emblem on the left and the exact text "RAMVI" on the right in custom clean bold rounded geometric uppercase lettering, dark deep violet, excellent spacing and optical balance. The mascot represents the entire modular AI platform, not only the Character module. Transparent background, generous clean margins, no background plate, no slogan, no mockups, no extra variants or labels.
