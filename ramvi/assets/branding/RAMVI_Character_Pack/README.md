# RAMVI 2D Character Pack

Персонаж собран на основе загруженного логотипа RAMVI. Все спрайты представлены отдельными PNG с прозрачностью, размер холста **768×768** и одинаковый якорь (центр).

## Состав
- `sprites/expressions/` — 13 эмоциональных состояний.
- `parts/body/visor_without_features.png` — тело и лицевая панель без глаз и рта.
- `parts/eyes/` — 10 вариантов глаз (прозрачные накладываемые слои).
- `parts/mouths/` — 10 вариантов рта (прозрачные накладываемые слои).
- `sprites/turns/` — 5 упрощённых вариантов поворота (деформация исходного изображения, **не** настоящие боковые ракурсы).
- `animations/` — покадровые PNG: `idle`, `blink`, `talk`, `nod`, `shake`.
- `atlases/` — игровые сеточные атласы PNG и JSON-карты координат.
- `previews/` — демонстрационные GIF и обзор PNG.
- `source/` — исходный логотип и концепт-борд.
- `character.json` — манифест слоёв и анимаций.

## Интеграция
Для композитинга рисуйте `parts/body/visor_without_features.png`, затем `parts/eyes/<mode>.png`, затем `parts/mouths/<mode>.png` с координатами (0,0). Оба слоя имеют холст 768×768, поэтому совмещаются без дополнительного позиционирования.

Для анимаций последовательно показывайте PNG из `character.json` → `animations` с `duration_ms` между кадрами. `idle` — 115 мс/кадр; `blink` — 100 мс/кадр; `talk` — 95 мс/кадр.

## Ограничения
Эмоции и кадры idle подготовлены из одного фронтального ракурса. Повороты — стилизованные 2D-трансформации; они не являются полноценной покадровой перерисовкой профиля/затылка. Предпросмотр концепта не является редактируемым PSD или SVG. Визуальные детали новых глаз/рта нарисованы отдельно и могут слегка отличаться от исходного логотипа.
