# ADR-0002: модульная платформа RAMVI

Статус: принято. Основание — архитектурное дополнение к Character Module; исполнение и приёмка отслеживаются в пунктах 2.9–2.16 [PLAN.md](../PLAN.md).

## Решение

RAMVI остаётся платформой. Вычислительный Engine не зависит от функциональных модулей. Тонкий Module Host и публичные контракты размещаются в `ramvi_service`; Character подключается как необязательный модуль по тому же контракту, что и будущие расширения. В Core нет предметной логики характера, эмоций, речи и анимации.

Используются явная регистрация доверенных пакетов, версионированный манифест, ленивый initialize/activate и отдельные worker-процессы. Worker использует общий ProcessSupervisor Engine, а не собственный второй координатор процессов. Host определяет идентичность, scope данных и разрешений; вывод LLM не выдаёт права и не меняет владельца запроса.

Общая LLM и ресурсы арендуются по владельцу через FIFO/квоты; остановка одного модуля не отменяет чужой запрос и не выгружает общую модель другого активного потребителя. Модули используют общие версионированные события и bounded queues. Scoped Services обслуживают только namespace модуля; миграции, update и rollback не заменяют данные соседей.

Optional Context Provider разделяет чтение UI, Screen, Agent Control и внешнюю передачу текста/изображений. Изображения требуют image-input capability провайдера; скрытого облачного fallback нет.

## Границы

Основа этих контрактов реализована. Сам Character, продуктовые Chat/Agent, UI, полный Storage, постоянный credential store и OS context adapters относятся к следующим этапам. Scoped complete пока выдаёт один итоговый ответ; потоковый provider adapter подключается отдельно.

Доверенные Python-модули не являются произвольным враждебным кодом: scoped API и отдельный worker не объявляются OS sandbox. Store, маркетплейс, подписи и доставка сторонних пакетов не входят в это решение.

Детали контрактов, реализации и проверок приведены в [MODULE_CORE.md](../architecture/MODULE_CORE.md); порядок внедрения Character — в [MODULES_AND_CHARACTER_PLAN.md](../architecture/MODULES_AND_CHARACTER_PLAN.md).
