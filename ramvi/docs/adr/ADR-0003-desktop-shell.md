# ADR-0003: оболочка настольного приложения

Статус: **принято** 2026-11-16. Решение владельца: **Avalonia + C#**. Основание — проверка на Windows: Tauri без WebView2 Runtime не запускается, а пользователь не должен ставить дополнительные программы. Пункт 3.1 [PLAN.md](../PLAN.md).

## Решение

Оболочка RAMVI пишется на **Avalonia 12 / .NET 10, C#**. Поставка — self-contained single-file exe с trimming, без внешних зависимостей: .NET и рендер (Skia) входят в exe.

Оболочка — только окно и интерфейс. Модель, Module Host, аудио и worker-процессы остаются в Python-сервисе (`ramvi_service`) и движке; оболочка общается с сервисом по локальному HTTP (пункт 2.8). Решение не меняет движок и контракты модулей.

## Рассмотренные варианты

1. **Tauri 2 + Vue/TypeScript** — кандидат из ТЗ: нативная часть на Rust, интерфейс рисует системный WebView2. **Отклонён**: требует WebView2 Runtime, которого может не быть на чистой Windows (см. проверку 5).
2. **Avalonia 12 + C#** — собственный рендер на Skia, внешних зависимостей нет. **Выбран.**

## Размер сборки

Пустые приложения из официальных шаблонов (`create-tauri-app --template vue-ts`, `dotnet new avalonia.app`), дополнены полем ввода, кнопкой и режимом прозрачного окна. Собраны 2026-11-16 на Mac arm64 под Windows x64.

| Вариант | Файлы поставки | exe, байт | zip -9, байт |
|---|---|---:|---:|
| Tauri 2.12.5, release, `--no-bundle` | 1 exe + WebView2 в системе | 4 393 984 | 1 769 167 |
| Avalonia 12.1.6, .NET 10, single-file, trimmed | 1 exe | 39 470 995 | 16 318 069 |
| Avalonia 12.1.6, то же без trimming | 1 exe | 103 504 206 | 43 752 118 |

Размеры zip — для пустых шаблонов; версии с полем и прозрачным окном отличаются на десятки КБ (exe 4 297 216 / 39 483 283 / 103 508 302 байт). Trimming Avalonia — 0 предупреждений IL. Разница 2 МБ против 16 МБ мала рядом с поставкой модели и Python-сервиса.

## Проверка на Windows

Тестовый ноутбук, Windows 11 Pro 26200, один монитор 1920×1200, масштаб 125 % (120 dpi), WebView2 Runtime 157.0 установлен. Приложения запускались в интерактивном сеансе пользователя через планировщик задач с **ограниченным токеном**: метка целостности S-1-16-8192 (Medium), прав администратора нет. Три прогона 2026-11-16, 07:08–07:13 UTC.

### 1. Запуск из папки, копия папки, другая буква диска

Все три варианта запустились из исходной папки, из копии в другом каталоге и через подставленный диск `R:` (`subst`). Отличий во времени и памяти между этими местами нет.

### 2. Время запуска и память

Окно — первое видимое окно процесса; «готово» — интерфейс сообщил, что отрисован (Avalonia: после `Opened`; Tauri: два кадра после монтирования Vue). Память — сумма по дереву процессов через 3 с после готовности.

| Вариант | окно, мс (3 запуска) | готово, мс | рабочий набор, МБ | private, МБ | процессов |
|---|---|---|---:|---:|---:|
| Tauri | 315 / 47 / 35 | 1303 / 430 / 391 | 336–371 | 164–177 | 7 (1 + 6 msedgewebview2) |
| Avalonia trimmed | 886 / 786 / 790 | 1076 / 976 / 980 | 149–168 | 120–131 | 1 |
| Avalonia без trimming | 700 / 642 / 651 | 891 / 830 / 842 | 156 | 120–121 | 1 |

Tauri быстрее показывает интерфейс (~0,4 с против ~1 с после первого запуска), но занимает примерно в 2 раза больше памяти. Avalonia без trimming запускается на ~0,14 с быстрее trimmed — цена trimming во времени запуска.

### 3. Ввод с клавиатуры

Настоящий ввод через `SendKeys` (тестовая строка + Enter), только если активное окно — проверяемое. Успех — приложение записало ответ «Hello, <строка>!».

- Avalonia trimmed — 2 из 2, без trimming — 1 из 1.
- Tauri — 6 из 9. **В каждом из трёх прогонов первый запуск** не принял ввод и не закрылся по `WM_CLOSE` за 5 с, хотя окно отвечало системе (`SendMessageTimeout` успешно) и было активным; следующие запуски работали. Причина не установлена; на решение не повлияла.

### 4. Прозрачное окно поверх других, click-through

Окно без рамки, поверх всех, прозрачный фон и красный квадрат 40×40 в углу; click-through — `WS_EX_LAYERED | WS_EX_TRANSPARENT` (Tauri — `set_ignore_cursor_events`, Avalonia — WinAPI после `Opened`).

| | Tauri | Avalonia (оба) |
|---|---|---|
| Флаги layered / transparent / topmost | да / да / да | да / да / да |
| Точка в центре окна принадлежит окну под ним (`WindowFromPoint`) | да | да |
| Пиксель в центре до и после закрытия совпадает (фон виден) | да | да |
| Красный квадрат виден (255,0,0) | да | да |

Обе оболочки проходят. Не проверены: возврат управления (выключение click-through по горячей клавише), два монитора с разным DPI — второго монитора не было.

### 5. Нет WebView2 Runtime (только Tauri)

Удалять системный WebView2 нельзя, поэтому его путь подменялся пустой папкой (`WEBVIEW2_BROWSER_EXECUTABLE_FOLDER`). Tauri показывает диалог «Error: Could not find the WebView2 Runtime. Make sure it is installed or download it from …» и пустое окно; процесс сам не завершается. То есть без WebView2 приложение не работает, а пользователю предлагают ставить его отдельно. Avalonia от WebView2 не зависит.

## Последствия

- Каталог `ramvi/desktop/` — проект Avalonia (C#), не Tauri/Vue.
- Правила стиля для C# (форматирование, nullable, предупреждения как ошибки) и проверка в CI задаются в первом пункте, который добавляет код оболочки.
- Click-through и прочие возможности окна для Overlay/Companion (3.13, этап 9) делаются через WinAPI внутри адаптера окна; на других ОС это отдельные реализации.
- Строки интерфейса — через каталог переводов 3.14; Avalonia-ресурсы не должны стать вторым каталогом.

## Как воспроизвести сборку

```
# Avalonia (.NET SDK 10, шаблоны Avalonia.Templates)
dotnet new avalonia.app -o shell -n RamviShell
dotnet publish shell -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:DebugType=none -p:PublishTrimmed=true

# Tauri (нужны Node, Rust, цель x86_64-pc-windows-msvc, cargo-xwin, LLVM в PATH)
npm create tauri-app@latest shell -- --template vue-ts --manager npm --yes
cd shell && npm install
npx tauri build --runner cargo-xwin --target x86_64-pc-windows-msvc --no-bundle
```

На macOS 14 Homebrew больше не собирает готовый LLVM; для Tauri использовался официальный архив LLVM 23.1.5 для macOS ARM64 (`clang-cl`, `llvm-rc`, `lld-link`, `llvm-lib`). Исходники пробы, exe с SHA256, скрипт замера и сырые результаты трёх прогонов лежат в игнорируемой папке результатов и в git не входят.
