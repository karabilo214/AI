# Character 9.8: локальный голос и подключаемые TTS API

2026-11-19, Character 0.6.0. По выбору владельца основной провайдер — системный
локальный голос, внешние API подключаются отдельно. Озвучка по умолчанию выключена.

## Что работает

В разделе Character появились выбор провайдера/голоса, включение новых ответов,
пробная фраза и Stop. В озвучку поступают только проверенные `segment` из Response
Planner. Сырые токены, управляющие записи и кандидаты памяти не произносятся.
Текстовый диалог работает при выключенном TTS или ошибке синтеза.

Core содержит общий контракт `SpeechRequest`/`AudioPiece`, адаптеры и аудиовыход;
Character задаёт эмоциональную инструкцию и управляет собственной очередью.
Методы `speech.catalog/configure/key/start/status/cancel` требуют права `speech`.
Владельца задаёт scope, чужие задания нельзя прочитать или отменить. Аренда
`audio_output` общая. Свой голосовой ввод приглушается на время вывода через уже
существующий playback gate; чужая микрофонная сессия не меняется.
Это полудуплексный режим, не акустическое эхоподавление.

Настройки TTS хранятся в пространстве модуля. Ключи `tts_openai`, `tts_gemini`,
`tts_elevenlabs` — в scoped хранилище секретов ОС; ключ STT `voice/api_key` с ними
не связан. Ключ не возвращается в ответе и не записывается в JSON настроек.
Поле ключа очищается и после успешного сохранения, и после ошибки. Пустое поле при
сохранении удаляет ключ. Вызов внешнего синтеза требует отдельного разрешения
`remote_text_enabled`; до него ключ не читается и провайдер не создаётся.
Контракт принимает текст, не запись микрофона. Разрешение/ключ внешнего STT не
разрешают внешний TTS. Адреса API фиксированы, перенаправления не выполняются.

## Возможности именно этих адаптеров

| Адаптер | Голоса/языки | Эмоция | Поток | Таймкоды | Отмена |
|---|---|---|---|---|---|
| System | Установленные голоса macOS/Windows, язык из инвентаризации | Обычная интонация, явный fallback | Нет: сначала WAV, затем PCM блоками | Нет | Свой процесс и его дочерние процессы |
| OpenAI | Каталог встроенных голосов, RU/EN | Текстовая инструкция; точность интенсивности не гарантируется | PCM из HTTP | Нет | Закрытие соединения |
| Gemini | Каталог встроенных голосов, RU/EN | Текстовая инструкция, без обещания точного соответствия | В этом адаптере нет | Нет | Закрытие соединения |
| ElevenLabs | Встроенный George, multilingual v2, RU/EN | Обычная интонация, явный fallback | В этом адаптере нет | Символьные, от провайдера | Закрытие соединения |

Ограничения и источник/дата стоимости доступны через каталог
[`providers.json`](../../service/ramvi_service/speech/providers.json).
`streaming` описывает реализованный адаптер, а не все возможности поставщика.
Закрытие HTTP не обещает отмены уже начисленной оплаты. Символьные метки не являются
фонемами/виземами. Невалидные времена отвергаются; слишком большая разметка заменяется
на `kind=none, reason=alignment_size_limit`, чтобы не превысить размер RPC.
`submitted_audio_s` — длительность отправленного в устройство PCM, не playback clock.
Синхронизация анимации и строгая отмена всего поколения ответа остаются в следующих пунктах плана.

## Источники API и стоимости

Проверка документации: 2026-11-19. Это снимок опубликованного тарифа, не расчёт счета.

- [OpenAI Speech](https://developers.openai.com/api/docs/guides/text-to-speech),
  [модель и тариф](https://developers.openai.com/api/docs/models/gpt-4o-mini-tts):
  `gpt-4o-mini-tts-2025-12-15`, USD 0.60 за миллион входных текстовых токенов,
  USD 12 за миллион выходных аудиотокенов.
- [Gemini Speech](https://aistudio.google.com/docs/speech-generation),
  [тариф](https://aistudio.google.com/docs/pricing#gemini-3.8-flash-tts):
  `gemini-3.8-flash-tts`, Interactions API, USD 0.50/9 за миллион входных текстовых /
  выходных аудиотокенов; опубликованная временная цена до 2026-12-31.
- [ElevenLabs with timestamps](https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps),
  [тарифы](https://elevenlabs.io/pricing/api): `eleven_multilingual_v2`, опубликовано
  «от USD 0.08 за 1000 символов», зависит от плана. Возможности v3 здесь не заявлены.

## Проверки и границы результата

Итог связанных проверок: 279 Python, 34 Avalonia; Ruff/mypy без ошибок,
локализация RU/EN — 705 ключей без ошибок. Полный набор проекта не запускался.

- Реальный macOS `say`: три свежие RU/EN/смешанные фразы, PCM 16 кГц; короткая фраза
  прошла через физический аудиовыход. Проверены ненулевая амплитуда и разные хеши
  трёх фраз (тишина/повтор одной записи проверку не проходят). Три отмены синтеза
  и отмена уже начавшегося вывода завершились, аренд после них нет.
  [Данные Mac](character_checks/speech/mac.json),
  [повторяемый скрипт](character_checks/speech/native_check.py).
- Реальный Windows System.Speech: инвентаризация Irina/Zira, три новые фразы,
  синтез и физический аудиовыход, отмена собственного процесса, затем ноль аренд.
  [Данные Windows](character_checks/speech/windows.json).
- После Windows-проверки собственных процессов и отметки занятости нет,
  видеопамять свободна; задания проверки/автоостановки удалены.
  [Уборка](character_checks/speech/cleanup.json).
- Облачные протоколы проверены **отдельно на loopback HTTP-сервере**: заголовки,
  модели, инструкции, форматы PCM/base64, символьные метки, отказ от redirect,
  отмена зависшего чтения. Платные live-вызовы и качество облачных голосов без
  пользовательских ключей **не проверены**. Их нельзя считать сравнением качества.
- Реальный worker Character проверен через Scoped Services: preview при выключенной
  озвучке, завершение, suspend и освобождение своих ресурсов. Проверены отключённый
  вывод, fallback эмоции, чужой owner, отдельные ключи/разрешения, heartbeat,
  поздний сегмент другого ответа и ограничение очереди.
- Wheel установлены вне checkout: нативный worker синтезировал PCM, каталог и
  PowerShell-адаптер входят в пакет. [Проверка](character_checks/speech/wheel.json).
- UI проверен headless с раскрытыми настройками;
  [снимок](character_checks/speech/ui.png). Код CUDA/inference не менялся.

Предельные размеры/сроки в коде — ограничения, не замеры скорости: текст сегмента
2048 UTF-8 байт, очередь Character 8 сегментов, PCM до 120 с, ответ HTTP до 12 МиБ,
ожидание аренды до 10 с, сеть до 15 с на операцию, нативный синтез до 45 с.
Строгая защита всех потребителей по поколению ответа, backpressure и повтор без
дублирования относятся к 9.9; восстановление устройств/провайдеров — к 9.10;
слепая оценка ударений, смешанных языков и эмоций — к 9.23. Эти пункты не закрыты.
