# RAMVI — экзамен 1 ТЗ на Windows (пункт 3.10), 2026-11-16

Сценарий пользователя: скачанный ZIP распакован на рабочий стол, `RAMVI.exe` запущен в сеансе
обычного пользователя **без прав администратора**, мастер первого запуска пройден, модели подключены
через окно выбора файла, вопросы заданы в чате. Окном управлял сценарий через Windows UI Automation
(щелчки мышью и ввод с клавиатуры); владелец наблюдал экран.

## Машина

Ноутбук Windows 11 x64: AMD Ryzen 7 260 (8 ядер / 16 потоков), 16 ГБ RAM, NVIDIA RTX 5060 Laptop 8 ГБ,
драйвер 616.92. Перед экзаменом по решению владельца удалены установленный Python 3.12 и Python
Launcher (PATH и реестр чисты, `where python` находит только заглушку Microsoft Store), кеши triton,
pip и RAMVI; окружение разработки и модели HF перенесены в архив. CUDA Toolkit не установлен.
**ОС не переустанавливалась** — на машине остаются драйвер NVIDIA (требуется по ТЗ) и другие программы.

## Модель

Основная — Qwen3-14B GGUF Q4_K_M (файл Ollama `sha256-a8cc…`, тот же, что на этапах 1–2), предсказатель
(draft) — Qwen3-0.6B GGUF Q4_K_M: сервис выбирает его автоматически. План размещения: 20 слоёв на GPU,
9 подкачка по шине, 11 гибридных — как в эталоне этапа 2. Ответы чата — жадный выбор.

## Найдено и исправлено экзаменом

- **Оболочка отправляла тела POST без `Content-Length`** (`JsonContent`, передача частями), а сервис
  (`http.server`) такие тела не читает: не работали импорт модели, отправка сообщений, настройки,
  завершение мастера. Тела теперь сериализуются заранее; добавлен сквозной тест «клиент оболочки ↔
  настоящий сервис» (со старым клиентом падает).
- **Чат не просил жадный выбор**: движок по умолчанию берёт temperature 1.0 — ответы случайны, а
  предсказатель почти бесполезен. Чат шлёт temperature 0; поддельный движок тестов требует это.
- **Предсказатель не подключался.** Сервис выбирает самую маленькую другую плотную qwen3 (не меньше
  чем в 8 раз меньше основной) и передаёт её движку; включает ли её план, решает движок.
- Ошибки подготовки экзамена (не продукта): копирование `robocopy /XD data models` выбросило из
  комплекта `torch\utils\data` и `transformers\models` — приложение честно показало «Бэкенд не найден»;
  сценарии PowerShell без BOM не разбирались; кнопки Avalonia не принимают Invoke через UI Automation.
