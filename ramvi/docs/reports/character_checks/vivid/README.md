# 9.32 — яркие профили: проверка судьёй

Скрытые сценарии (`vivid_dialogues.py`, в промпты не попадают): по 2 диалога из 6 реплик для
«Злого» и «Подкольщика», мат разрешён (уровень 2), персонаж — облако OpenAI gpt-5.5, по 2
запуска. Судья (`vivid_judge.py`, gpt-5.5) вслепую сравнивает две стенограммы, каждую пару
дважды с переставленным порядком; победа — только если выбор совпал оба раза.

**Контроль судьи** (заведомо решаемо: «Обычный» профиль против нового на тех же репликах):
новый злее/смешнее в 7 парах из 8, 1 — несогласованно ([judge_control.json](judge_control.json)).

**Новая версия против старой** (старая — коммит до 9.32 в git worktree):
новая выиграла 6 пар из 8, старая 1, несогласованно 1 ([judge_new_vs_base.json](judge_new_vs_base.json)).
Средняя оценка 1–10: «Злой» 7,75 против 6,6; «Подкольщик» 7,5 против 6,1. По сути отвечали
обе версии во всех парах (злость не заменяет ответ).

**Найдено по ходу:**
- грубость модель отмечает как «напряжённо» (tense), а правила считали это серьёзным и
  сдерживали злого — исправлено до сравнения: злого сдерживает только «serious»;
- словесный тик — «, бля.» в конце фразы: 29 из 48 ответов у старой, 26 у новой. После правила
  разнообразия мата — 13 из 48 ([dialogues_new_tic.json](dialogues_new_tic.json); 3 ответа из
  48 не получены — закончились кредиты OpenAI). Судьёй эта версия не оценена.

Предупреждение: судья — модель того же семейства, что и персонаж; оценка «смешно» — мнение
модели, не людей.

Персонаж — gpt-6-sol, судья — gpt-6.2-sol (подписка через Codex CLI, 7.12); старая версия —
модуль персонажа до 9.32 при текущем сервисе. По 2 запуска, 48 реплик на версию.

|---|---|---|

По сути отвечали все версии во всех парах. Тик «, бля.» — 12 из 48 у новой, 14 у старой; «бля»
в 35 из 48 ответов новой: на этой модели правило разнообразия почти не действует — модель держится
первого слова из списка примеров в правиле мата (гипотеза, не проверена).

Контроль «смешно» не пройден чисто: на просьбах «расскажи что-нибудь / давай ещё» (событие
request) подкольщик по правилу инициативы загадывает избитую загадку или викторину, а «Обычный»
рассказывает историю с развязкой — судья выбирает историю. Исправление (событие «просит
развлечь» → анекдот) — следующий шаг, с маленькой проверкой.
