# Экзамен модульности (пункт 8.9, CORE-MOD-09)

Дата: 2026-11-19, Mac, настоящий сервис, HTTP, SQLite и процессы модулей; движок тестовый. Тест: `tests/test_exam_modularity.py`, прогнан 3 раза подряд.

## Сценарий второго модуля `probe`

Модуль `probe` устанавливается своим пакетом (`ramvi.module/1`): свой код, своя SQL-база, настоящий процесс. В активном состоянии он держит микрофон (`audio_input`) и подписку на события. Рядом всё время работает модуль `other`.

| Шаг | Проверено |
|---|---|
| Нет модулей, нет Character | чат отвечает — исходные замеры |
| Установлен | зарегистрирован, процесс не запущен |
| Активен | держит микрофон и подписку, пишет в свою базу |
| suspend → resume | данные на месте, модуль отвечает |
| Падение процесса (`os._exit`) | его аренда и подписка освобождены; `other` — тот же процесс; чат отвечает |
| deactivate | аренд и подписок нет, процесс завершён |
| Обновление 1.0.0 → 1.1.0 (миграция) и откат | данные своей версии; `other` не перезапускался |
| Выключен → включён | процесса и регистрации нет, после включения данные на месте |
| Удалён без purge | кода нет, база модуля сохранена до явного выбора |
| Итог | все 3 процесса модулей завершены, `other` работал одним процессом до конца |

## Character

Настоящий модуль Character (`modules/character` из комплекта): установлен (раздел есть) → выключен (раздела и регистрации нет, чат отвечает, файл в его данных не тронут) → включён (раздел вернулся).

## Замеры относительно исходного состояния (один прогон, тестовый движок)

| | |
|---|---|
| Медиана ответа чата до / после всего сценария | 74,7 / 77,3 мс |
| RSS процесса сервиса: с активным модулем / после сценария | +0,6 / +1,2 МБ |

Это замер одного прогона на тестовом движке: «нулевой стоимости» он не доказывает. VRAM здесь не измерялась: тестовый движок видеопамять не использует, а модули своей видеопамяти не держат.

Найдено при написании экзамена: проверка «раздела выключенного модуля нет» сравнивала с неверным id раздела и проходила всегда. Исправлено, и добавлена проверка, что до выключения раздел есть.
