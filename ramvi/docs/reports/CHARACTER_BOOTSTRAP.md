# Character: жизненный цикл и первый проигрыватель

Дата: 2026-11-19. Принят 9.1; подготовлены ресурсы и первый renderer для 9.11.
Полный Character, LLM-диалог и TTS этим отчётом не заявляются.

Модуль `character/ramvi_character` запускается стандартным Module Host в отдельном
worker. Текстовая активация не требует модели, аудио, renderer или human_brain.
Свой checkpoint переживает suspend/resume, deactivate/activate и новый Host.
Соседний worker остаётся с тем же PID и состоянием после остановки Character.
Старые незавершённые презентации не перезапускаются.

Ресурсы вынесены в самостоятельный пакет: 72 RGBA PNG 768×768 и 62 WAV.
Отдельно от пакета работает Avalonia renderer. Раздел «Персонаж» появляется
при установленном модуле; картинки загружаются после его активации. При уходе
в чат или закрытии визуального дерева таймер и bitmap-кэш освобождаются,
черновик чата сохраняется. При ошибке ресурса отображение прекращается
с сообщением, без остановки других разделов.

Согласованные изменения:

- nod/shake: 2×; остальные движения: 1×.
- В idle отсутствует встроенное моргание. Старые idle-кадры не попали в пакет.
- Talk/no не запускают звуковые эффекты. Электронные talk_*, shake_head и beep_no
  исключены из рабочего набора; будущая речь — через TTS.
- Эмоция меняется независимо от движения; во время разговора его фаза сохраняется.
- Модуль принимает только разрешённые emotion/animation, не пути или команды.
