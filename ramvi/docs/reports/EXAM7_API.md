## Экзамен 8: сессии и смена режима

| Проверка | Итог |
|---|---|
| Повторяемость: три вопроса дважды подряд в одиночку | ответы совпали (иначе сравнение не имело бы смысла) |
| Два клиента одновременно, вопросы в разном порядке, 12 ответов | все 12 совпали с эталоном |
| Смена размещения запрошена посреди чужого длинного ответа (200 токенов) | смена дождалась конца ответа (слот взят после него), ответ совпал с эталоном |
| Ответы в гибридном режиме | повторяемы и совпали с ответами полного режима |
| Возврат к полному размещению | ответы снова совпали с эталоном |

| Режим | Слои (план движка `/engine/metrics`) | Видеопамять (`nvidia-smi`) |
|---|---|---|
| полный (авто) | 36 на видеокарте | 5982 МиБ |
| гибрид (`resident=20`) | 20 на видеокарте, 7 потоком, 9 на процессоре | 4246 МиБ |

Смена размещения шла тем же путём, что в приложении: слот общей очереди (`SharedLLM.exclusive`), затем `EngineManager.ensure`.

## Экзамен 7: два ключа раздельно

Ключи A и B работали одновременно (A — два вопроса, B — один):

| Ключ | Запросов | Токены запроса: сервис / клиент видел | Токены ответа: сервис / клиент видел | Время работы модели |
|---|---|---|---|---|
| A | 2 | 70 / 70 | 89 / 89 | 4,6 с |
| B | 1 | 25 / 25 | 80 / 80 | 4,8 с |

Отзыв: A генерировал длинный ответ, B ждал в очереди; ключ A отозван через секунду после начала B. Ответ A оборван (29 символов из 579), запрос в движке остановлен (`stopped=1`); B получил полный ответ, совпавший с эталоном, ошибок у B 0. Следующий запрос A — 401 (`AuthenticationError`), следующий запрос B — ответ, совпавший с эталоном.

## Что нашла проверка и что исправлено

1. **Подсчёт токенов полагался на случай.** Разбор ответа заходил во вложенный блок `ramvi_metrics`, и у потока OpenAI (движок кладёт `usage` в поток только по `stream_options.include_usage`) токены брались из метрик случайно. Теперь: сначала `usage` формата ответа (OpenAI, Anthropic, Ollama `total_output_tokens`), а если его нет — счётчики этой генерации из `ramvi_metrics` (у метрик свой `generation_id`). Проверено на настоящем движке — 120/20 вместо 90/15 без запасного источника.
2. Ошибки скрипта (не сервиса): встроенный Python комплекта не читает `PYTHONPATH` (свежий код подключается загрузчиком), в `anthropic` 2.10 нет `temperature` у `messages.create/stream`.

Результаты (json) в git не кладутся: числа — в этом отчёте.
