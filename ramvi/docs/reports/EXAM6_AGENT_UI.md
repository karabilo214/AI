# Экран и настройки агента (6.13)

Дата: 2026-11-18. Дополнение к [сервисному экзамену](EXAM6_AGENT.md).

Реализованы экран проекта/модели/задачи, Stop, журнал, diff до применения,
явные решения пользователя, контрольные точки лимитов, история, откат и
объяснение изменения. Вкладка «Агент» появляется при установленном модуле.
Она сохраняет права, защитные ограничения, доступность инструментов, лимиты
(включая «без ограничения»), контекст модели и очистку журнала.
Выбор приложения и гранты Screen / UI Context / Agent Control независимы.
Сохранение прав останавливает старую задачу, чтобы она не продолжила работу
с прежними разрешениями. Маршруты оболочки доступны только через защищённый
локальный UI API; модуль не может менять эти настройки через RPC.

Поле задачи использует оформление и поведение обычного чата: вложения,
микрофон, запись с таймером/уровнем/отменой, распознавание, Enter для отправки
и Shift+Enter для новой строки. Используется один общий VoiceViewModel;
распознанный текст направляется в исходное поле, черновик чата сохраняется.
Переключение раздела отменяет запись. Вложения проходят тот же валидатор,
не расширяют доступ к папкам; переполнение контекста отклоняется до вызова модели.
