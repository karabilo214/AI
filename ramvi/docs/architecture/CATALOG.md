# Каталог моделей (4.2 MOD-01)

Код: `service/ramvi_service/catalog/`, тесты: `tests/test_catalog.py`.

## Что делает

Каталог читает по сети **только метаданные** моделей у доверенных провайдеров и
переводит их в одну схему `CatalogEntry`. Интерфейс и подбор модели (4.4–4.6, 4.11)
работают только с этой схемой и не знают, откуда пришла запись.

| Часть | Файл | Назначение |
|---|---|---|
| Схема записи | `entry.py` | `CatalogEntry`, проверка обязательных полей `problems()` |
| Адаптеры | `providers.py` | `HuggingFace`, `OllamaRegistry` — протокол `Provider` |
| Источники | `sources.py` | какие репозитории и теги читаются по умолчанию (только Qwen3) |
| Фильтр | `support.py` | показываются только подтверждённо поддерживаемые файлы |
| Сеть | `http.py` | только GET и HTTPS, лимит размера ответа, общий User-Agent |
| Каталог | `__init__.py` | `Catalog.refresh()` / `Catalog.view()`, JSON-копия на диске |

## Обязательные поля

По ТЗ: версия, ссылка, размер, контрольная сумма, архитектура, квантование,
лицензия, возможности. Запись без любого из них (или с адресом не HTTPS, с хешем
не `sha256:<64 hex>`) в каталог не сохраняется.

| Поле | Hugging Face | Реестр Ollama |
|---|---|---|
| `version` | коммит репозитория (`sha`) | SHA-256 манифеста тега |
| `url` | `/<repo>/resolve/<коммит>/<файл>` — привязан к ревизии | `/v2/<repo>/blobs/<digest>` |
| `bytes`, `checksum` | размер и `lfs.sha256` файла | размер и digest слоя модели (это SHA-256 файла) |
| `architecture` | `gguf.architecture` | `model_family` из конфига |
| `quantization` | из имени файла (`…-Q4_K_M.gguf`) | `file_type` из конфига |
| `license` | `cardData.license` | по тексту слоя лицензии (`apache-2.0`, `mit`, иначе `other`) |
| `capabilities` | из карты движка `ramvi_engine.capabilities` (2.1), не из обещаний провайдера | то же |

Закрытые (`private`/`gated`) репозитории и файлы, разбитые на части, не берутся:
загрузчик (4.3) скачивает один файл без входа в аккаунт.

## Что показывается

Только подтверждённо поддерживаемое (`support.CONFIRMED_QUANTS`): движок умеет такие
матрицы **и** файл такого вида проверен на железе.

| Архитектура | Кванты | Где проверено |
|---|---|---|
| `qwen3` | Q4_K_M, Q6_K, F16 | WIDE30 и экзамен 1 (Q4_K_M), B.4 (Q6_K), пункт 3.18 (F16) |
| `qwen3moe` | Q4_K_M | этап 2 (у экспертов движок принимает только Q4_K/Q6_K) |

Q8_0, Q5_*, BF16 и IQ* скрыты. Новый квант добавляется в список только после
проверки на железе. `view(include_unsupported=True)` возвращает и скрытые записи с
причиной (`format`, `architecture`, `quantization`, `fields`) — для диагностики.

## Сеть и офлайн

- `GET /ui/v1/catalog` читает только локальную копию
  `<папка данных>/catalog/catalog.json` и в сеть не ходит.
- `POST /ui/v1/catalog/refresh` опрашивает провайдеров. Запись копии атомарная
  (временный файл + `os.replace`).
- Если провайдер не ответил, его прежние записи остаются, у него появляется
  `error` = `{code: "catalog.unavailable", params: {provider}}`, а у всего ответа —
  `stale: true`. Записи другого провайдера обновляются как обычно.
- Повреждённая или чужая по версии копия даёт пустой каталог; приложение работает.
- Запросы не несут данных о пользователе и железе: только GET, User-Agent `RAMVI`,
  без cookies и ключей. Обычный HTTP разрешён лишь для 127.0.0.1 (тесты), переадресация
  тоже только на HTTPS.

Реестр Ollama (`registry.ollama.ai`) — тот же открытый реестр, из которого скачивает
сам клиент Ollama; отдельной публичной документации API у него нет. Если он изменится,
адаптер вернёт ошибку, и каталог покажет последнюю копию.

## Замер

Mac M1 Pro, 2026-11-17, настоящие Hugging Face и реестр Ollama, источники по умолчанию
(7 репозиториев, 12 тегов): обновление 13,8 с; показано 17 записей (Hugging Face 5 —
Q4_K_M 4B/8B/14B/32B/30B-A3B; Ollama 12 — Q4_K_M 0.6B…32B, 30B MoE и F16 0.6B…14B);
скрыто 22 (Hugging Face Q5_0, Q5_K_M, Q6_K, Q8_0). У репозиториев Qwen3-0.6B/1.7B-GGUF
есть только Q8_0, поэтому они не показываются. SHA-256 файла `qwen3:14b` из каталога
совпал с идентификатором весов, который движок посчитал по самому файлу в экзамене
этапа 1.
