# Безопасность и приватность (8.4, раздел 11 ТЗ)

Сводка: каждое требование раздела 11 ТЗ — чем оно выполнено и где проверено. Пункты, сделанные в других этапах, только перечислены со ссылкой.

| Требование ТЗ | Как выполнено | Проверка |
|---|---|---|
| Проверка источников моделей и контрольных сумм | каталог — только подтверждённые файлы ([CATALOG.md](CATALOG.md)); загрузка только по HTTPS (`web.check`, переадресация тоже), файл активируется только после совпадения SHA-256 из каталога, иначе удаляется ([DOWNLOADS.md](DOWNLOADS.md)) | `test_downloads.py` (`test_bad_hash_not_activated`, `test_download_activates_only_after_hash`) |

| Prompt injection: инструкции из файлов и ответов инструментов — не полномочия | доступ агента решает runtime (границы папки, права, подтверждения), а не модель ([AGENT.md](AGENT.md)); служебные поля `ramvi*`/`module_id` из тела внешних запросов отбрасываются ([EXTERNAL_API.md](EXTERNAL_API.md)) | `test_agent_*`, `test_api_modules.py` |
| Секреты маскируются в UI и логах | ключи клиентов API — только SHA-256 и подсказка `ramvi-…a1b2`; ключ стороннего API — в хранилище ОС (DPAPI / Связка ключей / Secret Service), не в `settings.json`; ключ движка — через окружение, не в командной строке; аргументы инструментов агента в журнале очищены (`redact`); **все ответы об ошибках интерфейсу проходят `redact.mask_value`** — ключи вида `ramvi-…`, `sk-…`, `AIza…`, `ghp_…`, значения после `Bearer`, `api_key=`, `token=`, `password=` заменяются началом и многоточием (например, ответ OpenAI «Incorrect API key provided: sk-…») | `test_security.py` (маскирование и ответы интерфейса), `test_client_keys.py`, `test_agent_tools.py` |
| Сетевое прослушивание выключено по умолчанию | внешний API — только 127.0.0.1; сеть — по явному включению, разрешённые адреса и ключ с правом `remote` | `test_api_network.py` (в т.ч. настоящее подключение через сетевой адрес) |
| На USB нельзя молча обещать аппаратную защиту ключей | ключи хранятся в хранилище ОС этого компьютера, а не в переносимой папке; под полем ключа API — подсказка «ключ на этом компьютере, на другом введите заново» (`voice.api_key_where`) | i18n-проверка, тесты оболочки |

| Телеметрия выключена; логи и диагностика наружу — только по согласию | телеметрии нет. Hugging Face в комплекте — офлайн (`HF_HUB_OFFLINE`) | `test_security.py::test_no_outbound_network_without_user_action` — запуск, экраны и ответ чата не открывают ни одного соединения наружу (контроль: ловушка ловит внешнее соединение) |
| Скачивание и распаковка ограничены по размеру и путям | загрузки: имя файла и путь проверяются (`safe_target`, ссылки наружу запрещены), место на диске проверяется заранее, **источник, приславший больше размера из каталога, останавливается, частичный файл удаляется** (заголовку сервера не доверяем); пакет обновления: пути только в разрешённых частях комплекта, размер и SHA-256 каждого файла | `test_downloads.py::test_source_sending_more_than_announced_is_stopped`, `test_path_protection`, `test_symlink_escape`, `test_updates.py` |

| Защита от удаления произвольных файлов пользователя | «Удалить модель» удаляет файл, только если его скачал RAMVI; подключённый на месте файл только забывается (`models.file_not_ours`); обновление не может тронуть данные, модели и настройки | `test_model_library.py`, `test_updates.py` |
