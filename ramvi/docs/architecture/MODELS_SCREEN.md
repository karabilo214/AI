# Экран «Модели» (4.11 UI-CATALOG-01)

Оболочка: `desktop/src/Ramvi.Desktop/ViewModels/ModelsViewModel.cs`, панель `ModelsPanel` в
`Views/MainWindow.axaml`, выбор модели по умолчанию в `SettingsViewModel`. Сервис:
`service/ramvi_service/model_library.py`, встроенный раздел `models` в `sections.py`.
Тесты: `desktop/tests/Ramvi.Desktop.Tests/ModelsTests.cs`, снимок `StyleTests.Snapshot_models_screen`,
`tests/test_model_library.py`.

## Что на экране

По иллюстрации ТЗ «Каталог моделей»:

- **Шапка:** заголовок и кнопка «Обновить каталог» (единственное действие экрана, которое идёт в
  сеть, — 4.2).
- **Поиск** по названию и кванту; **фильтры** «Все / Установленные / Подходят». «Подходят» —
  статус «Рекомендуется» или «Медленно» и модель подходит задаче профиля (4.5).
- **Карточка модели:**
  - название и строка «план · скорость · размер» — например «Гибрид GPU+RAM: 29 из 40 слоёв в
    видеопамяти · оценка ~4,6–8,3 токенов/с · 9,0 ГБ»;
  - статус совместимости цветом (4.4), а все причины и «почему не подходит задаче» — в подсказке;
  - плашка: «Установлена · Текущая» / «Установлена» / «Скачивается» / «На паузе» / «Доступна онлайн».
- **Действия карточки:**
  - «Скачать» с полосой прогресса, «Пауза», «Продолжить» и «Отменить» (4.3); прогресс обновляется
    раз в секунду, пока идут загрузки;
  - «Сделать моделью по умолчанию» (звезда) — модель новых чатов;
  - «Удалить» — вторым нажатием: первое спрашивает «Точно забыть?» / «Точно удалить файл?».
- **Нижняя строка:** какая модель выбрана для профиля и почему (4.6); если каталог не обновился,
  есть пометка «показана последняя сохранённая копия».

Одна и та же модель, установленная и в каталоге (скачанная из этой записи или тот же файл — те же
архитектура, размер и квант), — одна карточка.

## Где ещё

- В панели разделов появился встроенный раздел «Модели» (после «Чата»). Данные экрана грузятся
  при открытии раздела, а не при запуске приложения.
- **Настройки:** «Модель по умолчанию» — сохраняется вместе с остальными настройками; «Управлять
  моделями…» открывает экран «Модели». Удаление — на экране «Модели».
- После скачивания, удаления или смены модели по умолчанию список моделей чата обновляется сам.

## Сервис

| Запрос | Действие |
|---|---|
| `POST /ui/v1/models/{id}/default` | модель по умолчанию (тот же выбор, что запоминает чат) |
| `POST /ui/v1/models/{id}/delete {delete_file}` | забыть модель; чаты остаются без модели, замеры 4.7 удаляются |

Файл удаляется только при `delete_file=true` и только у модели, которую RAMVI скачал из каталога в
папку моделей. Подключённый на месте файл пользователя (импорт, папка Ollama) не удаляется никогда:
`400 models.file_not_ours`. Оболочка сама решает, просить ли удаление файла: да — для скачанных,
нет — для подключённых. Загруженная сейчас модель перед удалением выгружается.

  умолчанию, удаление с вопросом и правилом файла, рекомендация и устаревший каталог, открытие
  раздела и ссылка из настроек, сохранение по умолчанию из настроек, окно без экрана. Поломок
  поймано 5 из 5.

  методы клиента. Сервис: 5 тестов `test_model_library.py`.
- Снимки в светлой и тёмной теме (`RAMVI_SNAPSHOT_DIR`) совпадают по раскладке с иллюстрацией ТЗ.
- На Windows экран не проверялся.
