# Непрерывная проверка RAMVI (1.10)

Workflow [`ramvi-ci.yml`](../../../.github/workflows/ramvi-ci.yml) запускается на push, pull request и вручную. Он не использует модели, GPU или внешнюю рабочую машину. Права ограничены чтением репозитория; при новом коммите прежний запуск той же ветки отменяется.

## Состав

- **Package and checks** на Linux и Windows, Python 3.12: установка зафиксированной группы `dev`, Ruff lint/format, строгий mypy для нового кода, pytest, сборка wheel. Wheel устанавливается без зависимостей в отдельное временное окружение вне checkout; проверяются импорт, native/grammar-ресурсы и обе команды CLI. Здесь вычислительные зависимости отсутствуют: связанные с ними pytest-проверки явно пропускаются.
- **Engine unit tests (CPU)** на Linux, Python 3.12: отдельная установка `torch==2.15.0` из официального CPU-индекса и зависимостей пакета движка, `pip check`, pytest с вычислительными зависимостями и прежние тесты `llm_app/tests` через слой совместимости. Проверяется, что Torch собран без CUDA. Зависимость xgrammar может устанавливать Triton; наличие этого пакета не включает GPU и не превращает тесты в проверку GPU-ядер.

Клонируется полная история: сверка переноса должна иметь доступ к исходному коммиту. Правила `ramvi/.gitattributes` сохраняют LF в исходниках на обеих ОС, чтобы Windows checkout не менял хеши ядер и результат побайтовой сверки. Лимит лёгкой задачи — 15 минут, задачи CPU — 20 минут. Установка CPU-зависимостей выполняется отдельно, чтобы лёгкие проверки не зависели от PyTorch.

## Границы проверки

CI проверяет код и упаковку. Он не измеряет скорость генерации, не сравнивает ответы моделей и не исполняет Windows DLL. Эталон fp32, WIDE30 и проверка на целевой NVIDIA остаются отдельной приёмкой по пункту 1.9 [плана](../PLAN.md).

Подтверждённый [запуск GitHub Actions](https://github.com/karabilo214/AI/actions/runs/43488979984) для коммита `e2c8b69` завершился успешно во всех трёх задачах. Linux CPU: 48 проверок пакета и 89 прежних модульных тестов прошли. Windows: 43 проверки прошли, 5 пропущены без вычислительных зависимостей; lint, форматирование, mypy и изолированная установка wheel прошли. Лёгкая задача Linux также прошла. Это не заменяет GPU-экзамен.

Окончания строк исходников и Markdown закреплены как LF в `.gitattributes` продукта. Это сохраняет native-хеши и одинаковый результат форматирования Python-примеров на Windows и Linux.
